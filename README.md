# TSOnlineWarpRouteFinder

เว็บหาเส้นทางวาร์ปสั้นที่สุดของ TS Online จากข้อมูล `door.ini`

## ใช้งาน

1. เปิด `index.html`
2. ใส่ `ID Map` ต้นทางและปลายทาง
3. กด `หาเส้นทาง`
4. สลับดูผลลัพธ์ได้ทั้งแบบ `เส้นทางเต็ม` และ `WarpPortal`

## ไฟล์ที่ใช้

- `index.html`
- `styles.css`
- `app.js`
- `data/door-data.js`
- `.github/workflows/deploy-pages.yml`
