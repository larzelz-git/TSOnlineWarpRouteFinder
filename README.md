# TS Skill Tree Planner

เครื่องคำนวณอัปสกิล TS Online แบบผังต้นไม้

## ใช้งาน

1. เปิด `index.html`
2. เลือกธาตุ และระดับ (0/1/2/ฉายา)
3. คลิกสกิลเพื่ออัปเลเวล (+1)
4. คลิกขวาที่สกิลเพื่อลดเลเวล (-1)

## กติกาปัจจุบัน

- `Point` คือแต้มที่ใช้สำหรับอัปเลเวลแรก
- เลเวลถัดไปของสกิลเดียวกัน เพิ่มค่าใช้แต้มทีละ +1 (ปรับได้ใน `COST_GROWTH_PER_LEVEL`)
- เช็กเงื่อนไข `AND/OR` จาก `Pre1..Pre6`
- `AND` ต้องมีทุกสกิล pre อย่างน้อยเลเวล 1
- `OR` ต้องมีอย่างน้อย 1 สกิล pre ที่เลเวล 1 ขึ้นไป
- สกิลที่มีลูกถูกอัปอยู่ จะลดเลเวลไม่ได้

## แก้ข้อมูล

- ไฟล์ข้อมูลหลัก: `data/skills.tsv`
- ถ้าเปลี่ยนชื่อสกิล ควรรักษาความสอดคล้องกับชื่อที่ถูกอ้างใน `Pre`
